# 标签界面改进

以下记录 v0.3.0 的原始方案。v0.3.1 已按后续反馈取消待操作区和批量按钮，工作台改为点击即时保存；新建标签也立即添加到选中论文。右键菜单增加明确的选中／未选中／部分选中符号。

目标：按用户截图改成紧凑网格、顶部已添加标签、右键常用标签子菜单和阅读侧栏。

方案：工作台保留批量按钮；快捷入口点击即写入，混合状态点击补全到全部所选论文。通过官方 ItemPaneManager 注册侧栏，直接使用该侧栏 item，禁止使用后台文献列表选择代替阅读对象。常用标签可在管理页设置；未设置时优先自定义 # 标签。

步骤：
- [x] 新增 quick-tags.js，共享勾选状态、事务写入、右键菜单和侧栏生命周期。
- [x] app.js 增加已添加／待操作标签区，快速标签改成自动换行，管理页改成多列紧凑编辑。
- [x] bootstrap 加载快捷模块与本地化，build 打包所有依赖，版本升级 0.3.0。
- [x] 验证批量混合状态、只读禁用、阅读目标、插件清理与实际安装；输出工作台截图。

视觉：保留淡紫标签和蓝色操作，统一 32px 控件、8px 间距和清晰键盘焦点。顶部展示论文现有标签（部分覆盖有文字说明），勾选待操作标签另有预览。常用标签通过“常用”按钮固定，侧栏有搜索和管理入口。
