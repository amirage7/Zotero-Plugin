# Tag Studio 0.3.5 · Zotero 标签工作台

给 Zotero 10.0.x 提供可搜索的标签库、标签颜色管理、标签重命名和论文批量标签操作。已在本机 Zotero 10.0.6 的独立空白测试文库中通过实际安装和核心功能测试。

本插件是 [Zotero Plugin Collection](../../README.md) 中的一个独立插件。
源码目录：[plugins/tag-studio](https://github.com/amirage7/Zotero-Plugin/tree/main/plugins/tag-studio)。
当前安装包：[TagStudio-Zotero10-v0.3.5.xpi](dist/TagStudio-Zotero10-v0.3.5.xpi)。

## v0.3.5 自适应宽松模式

- 打开“标签工作台”，在上方右侧“列表显示”选择“紧凑 · 一行”或“宽松 · 自适应”，选择保存在本地。
- 自适应模式逐篇计算：所有可见标签列能放下一行的论文保持原行高，有任一标签列需要换行时才展开到两行。没有标签的论文也保持一行。超出两行的标签用 `+N` 表示，悬停可查看完整列表。
- 拉宽列后自动缩回一行，拉窄列后按需展开。虚拟列表使用每行高度，保证不同高度的论文行在滚动和选中时对齐。
- 调整列宽时重新计算可见标签，避免半截标签。切换模式保留选择及顶部可见行；禁用插件恢复 Zotero 原行高。
- 行高适配仅用于主论文列表，不改变分类树、PDF 阅读器和 Zotero 全局字体设置。适配使用 Zotero 10 列表内部行高接口，并在本机独立文库验证。

## v0.3.3 分类标签独立列

- 文献列表新增“研究主题、研究对象、研究方法、阅读进度、其他”五列，默认显示前三列。
- 保留“彩色标签”总览列。右键表头可选择显示的列，拖动表头调整位置和宽度；已有总览列的显示偏好保留。
- 各列只显示对应分类的标签，未分类标签归入“其他”。颜色保持原设置，悬停单元格显示完整标签列表。
- 修改分类后立即刷新列表中的归属列；仅显示 # 标签的设置适用于全部标签列。

## v0.3.2 按分类分区显示

- 快速打标签和标签库管理都按“研究主题、研究对象、研究方法、阅读进度、其他”分区，同类标签集中排列。
- 每区显示分类标题和当前可见标签数量，搜索时隐藏没有匹配标签的分类。
- 修改标签分类后立即移动到对应区域，保留原颜色及标签操作方式。
构建和完整测试说明见 [tests/README.md](tests/README.md)。

## 第一版支持

- 从当前 Zotero 文库读取所有已使用过的标签，包括导入的英文标签和 `#` 开头的自定义标签。
- 自定义 `#` 标签在最后一篇论文移除后仍保留在插件标签库，方便重用；手动新建的标签也可以在未应用到论文前保留。
- 在「标签库与颜色管理」中逐个选择颜色、修改标签分类、重命名标签。
- 为多篇选中论文批量添加或移除标签，保留论文现有的其他标签。
- 注册独立的「彩色标签」列；每个标签都能用自己的颜色显示，不受 Zotero 原生 9 个彩色标签的限制。
- 「仅看 # 标签」筛选；「彩色标签列仅显示 # 标签」显示开关。

## v0.3.1 界面与快捷标签

- 右键菜单显示“标签工作台”，悬停展开常用标签。勾选表示全部所选论文已添加；“部分已添加”表示仅部分论文具有该标签。点击立即添加到全部所选论文，已全部添加时点击移除。
- 工作台顶部显示论文已添加标签，多篇论文的部分覆盖标为“数量/论文数”。点击标签立即添加或移除；没有待操作区及底部添加／移除按钮。复选框直接反映论文已有标签，部分添加显示横线。
- 快速标签自动换行，管理页采用紧凑多列布局，并统一输入框、按钮与颜色控件的尺寸和对齐。
- 工作台可直接输入新标签名称，点击“创建并添加”或按回车，立即保存到选中论文；未选论文时可只创建标签。普通标签与 # 标签均支持，重复名称不会重复创建或移除已有标签。
- 右键快捷标签在名称左侧明确显示 ☑ 已添加、☐ 未添加、▣ 部分已添加，状态不依赖 Windows 是否绘制原生菜单勾选标记。
- 管理页“设为常用”控制快捷菜单和侧栏内容。尚未手动设置时默认展示前 24 个自定义 # 标签。
- 文献和 PDF 阅读页右侧信息栏增加“常用标签”区域及标签形侧边按钮，可搜索全部标签、即时添加/移除、创建并添加新标签，或打开管理工作台。阅读页操作当前打开 PDF 的父论文。
- 使用 Zotero 官方 ItemPaneManager 扩展接口。只读文库禁用快捷写入；禁用插件会注销侧栏、观察者、菜单和彩色列。
- 实际安装和功能测试使用独立测试文库，包括本地生成的 PDF 阅读页。测试报告为 `tests/desktop/result.json`；工作台截图为 `apply.png`、`manage.png`。离线回归还覆盖混合勾选和只读阻止写入。

## 安装（Windows Zotero）

1. **先备份 Zotero 数据目录**。此插件有修改真实论文标签的功能。
2. 下载 `TagStudio-Zotero10-v0.3.5.xpi`，**不要解压**。已安装旧版时可直接覆盖安装。
3. 打开 Zotero → **工具 → 插件**，点击插件页面的齿轮 → **Install Add-on From File / 从文件安装插件**，选择下载的 `.xpi`。也可把 `.xpi` 拖入插件窗口。
4. 在 Zotero 左侧选中要操作的文库及其论文，打开 **工具 → 标签工作台**。右键“标签工作台”可展开快捷标签或打开完整工作台。
5. 在标签工作台的「标签库与颜色管理」里调整颜色；切换到「快速打标签」给选中论文应用标签。
6. 在文献列表列标题处右键，勾选 **「彩色标签」**。如果你同时安装了 Zotero Style，可以把 Style 的 `#标签` 列隐藏，避免重复。

**重要：Zotero Style 的 `#标签` 列颜色不会自动跟随本插件。** 请使用本插件新注册的「彩色标签」列显示自定义色彩。

## 推荐使用流程

- 自定义标签统一以 `#` 开头，例如 `#信任`、`#VR实验`、`#行人`。
- 在管理面板的「仅看 # 标签」中快速筛选自己的标签，忽略论文导入的英文关键词。
- 一次选中多篇论文，打开工作台，点击未勾选或部分勾选的标签，立即添加到全部选中论文。
- 点击已勾选标签，立即从全部选中论文移除；其他标签保留。

## 注意与限制

- 本版仅处理**当前文库**的标签和当前选中的**常规文献条目**。选中子 PDF 时会尝试操作其父文献。只读群组文库可能不允许修改。
- 自定义颜色、分类等配置保存在 Zotero 本地首选项中，不等同于 Zotero 原生彩色标签，也不会直接同步到另一台电脑。
- 修改标签名称会影响当前文库中使用此标签的所有文献。合并到已有标签时有二次确认。
- 请在备份数据库后先用 1–2 篇测试论文确认功能。安装与核心功能已在 Windows Zotero 10.0.6 的独立测试文库验证；尚未针对所有群组文库和其他插件组合验证。
- 已有的标签内容存储在 Zotero 数据库中；安装插件不会自动覆盖、转换或删除论文标签。
- 卸载后，插件添加到论文的**真实标签依然存在**；自定义彩色列和面板消失，颜色偏好可能保留在本机配置中。

## v0.2.0 修复（Zotero 10）

- 将清单的兼容范围改为 Zotero 10.0.x；旧包的 9.0.* 兼容声明会被 Zotero 10 正式版拒绝。
- 使用 Zotero 10 的 `getSelectedLibraryIDs()` 取代已移除的旧接口；多文库选择时弹出提示，不自动选择某个文库修改。

- 插件 ID 与旧版一致，安装时可尝试直接覆盖安装。

**使用前：**请先备份 Zotero 数据，并在 1–2 篇测试论文上确认标签添加/移除正常，再批量使用。测试报告见 tests/desktop/result.json。
